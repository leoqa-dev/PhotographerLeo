JSON编辑器

直接编辑JSON配置文件。编辑完成后点击"下载JSON"，然后手动替换 data/albums.json 文件并提交到GitHub。

使用说明

如何添加新相册？

  1. 在 images/ 目录下创建相应的文件夹
  2. 将照片上传到该文件夹中
  3. 在"JSON编辑器"标签页编辑配置，添加新相册信息
  4. 下载编辑后的JSON文件
  5. 替换 data/albums.json 文件
  6. 提交更改到GitHub（git add . && git commit -m "Add new album" && git push）

JSON配置示例

{
  "id": "album-id",
  "title": "相册标题",
  "description": "相册描述",
  "category": "guangzhou",
  "tags": ["标签1", "标签2"],
  "coverImage": "images/path/to/cover.jpg",
  "date": "2024-01",
  "location": "拍摄地点",
  "photos": [
    {
      "id": "photo-001",
      "src": "images/path/to/photo.jpg",
      "title": "照片标题",
      "description": "照片描述"
    }
  ]
}

部署到GitHub Pages

  1. 将代码推送到GitHub仓库
  2. 在仓库设置中启用GitHub Pages
  3. 选择 main 分支的根目录
  4. 等待部署完成（通常1-2分钟）
  5. 访问 https://你的用户名.github.io/仓库名

修改管理员密码

编辑 js/admin.js 文件，修改 ADMIN_PASSWORD 常量的值。
